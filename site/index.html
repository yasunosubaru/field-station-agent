FieldStation
Hybrid.

野外台站，从此有人值守。

原版 NAS 套件、逆向重实现与 RPA 驱动，收进同一个窗口。武汉大学 · 2026 大创。

下载 GUI 安装包 ↗ 看一条流程怎么跑 ↗

三合一。 一个安装包，三个部分。

original/

原版 NAS 套件

完整的 NovAtel Application Suite 2.11.0，1.44 GB / 413 文件。直接内嵌，不靠静默安装。

packages/

B 重实现

8 个零依赖 TypeScript 包。协议层 123 条消息、879 个字段，27 篇逆向分析文档。

workflows/

RPA 驱动层

8 条固定流程，原生对话框全自动。自带 Node 与 Python，目标机零依赖。

启动。 双击之后实际发生的事。

$ FieldStationHybrid.exe → extract payload → %LOCALAPPDATA%\AllPoweredFSA\app-1.0.0.0 → node server.ts --port 0 [listen] → WebView2 → My Applications → 5 cards: Manage · Playback · Convert · GRIT · Graph → attach agent-desktop.exe → ready ✓

流程。 gui.graph.newproject 怎么跑。

01healthautomatic
探测 7788 端口与会话健康度
06open_wizardautomatic
附加 Graph 进程（--remote-debugging-port=9224），打开 New Project 向导
10choose_folderautomatic
原生 Select Folder 对话框：agent-desktop 按 accessibility ref 定位，AttachThreadInput 绕过前台锁定
12choose_fileautomatic
Receiver Data 的 Open 对话框，同上机制；不再靠坐标点击
19approve_plothuman_gate
绘图前停下，等人确认；写盘不可逆的步骤不替人决定

19 步中 16 步自动、1 步人工闸门，其余为等待与断言。

边界。 不把做不到写成做完了。

human_gate

3 条写盘流程停在人工闸门。approve_plot、gui.app.install、gui.app.update 涉及不可逆写盘，自动走到闸门后由人批准。

hardware

3 条卡在硬件边界。设备新增、固件刷写、重启确认——代码与闸门已推到位，本机 /api/ports 只有蓝牙串口，缺真接收机做端到端。

n/a

11 项本机不适用。SPAN/IMU、双天线 ALIGN、PPP、电台、事件样本——OEM729 无对应硬件或授权，原版本机也只有空态。

frontend

包内前端是 0.1.10 版。为拿到正确的 My Applications 界面；工作树最新前端（含四视角代码）没有打进这个 exe。

unverified

原版静默安装分支未在干净机器实跑。本机已装原版，检测到后跳过；GUI 版直接内嵌原版套件，不依赖该分支。
