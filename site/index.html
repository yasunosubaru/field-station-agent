自动化流程

一条流程，
19 步走到人工闸门。

以 gui.graph.newproject 为例：从 SBF 新建 Graph 工程，原版 GUI 要连续穿过两个原生对话框。我们把它拆成状态机，16 步自动执行，最后一步留给人。

难点不在算法，
在对话框。

原生对话框没有 DOM，不能靠坐标点击。agent-desktop 按 accessibility ref 定位控件，AttachThreadInput 绕过前台锁定；每一步都带状态、锁与幂等校验。

19步状态机
16步自动执行
1步人工闸门

写盘不可逆的动作，不替人决定。

关键步骤 · 5 / 19
01health自动

先确认目标机可用：探测 7788 端口，读取会话健康度。状态不对就停在这里，不带着错误往下走。

端口探测会话健康
06open_wizard自动

附加已经运行的 Graph 进程（--remote-debugging-port=9224），打开 New Project 向导。不是另起一个窗口，是接上原来的那个。

CDP 附加Graph 进程New Project
10choose_folder自动

原生 Select Folder 对话框：agent-desktop 按 accessibility ref 定位控件，AttachThreadInput 绕过前台锁定，全程不依赖屏幕坐标。

辅助功能树前台锁非坐标定位
12choose_file自动

Receiver Data 的 Open 对话框，同一套机制。换对话框不换实现，坐标漂移不再是故障源。

Open 对话框同一机制
19approve_plot人工闸门

绘图前停下，等人确认。所有写盘不可逆的动作都收在这道闸门之后，机器只做到这里。

人工确认不可逆写盘
