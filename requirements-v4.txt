# ── 运行期补偿：上游漏声明，不装就跑不通（不是 import 失败，是运行期失败）──
#
# 补偿项一：llama-index-vector-stores-lancedb 漏声明 pandas
#   它的 base.py 第 33 行直接 `from pandas import DataFrame`，但 Requires-Dist
#   里没有 pandas。只装它声明的四个依赖（lancedb / llama-index-core / pylance /
#   tantivy）时，`import llama_index.vector_stores.lancedb` 抛
#   ModuleNotFoundError: pandas。必须显式钉住，否则"装完了"和"能用"之间有条暗沟。
pandas==3.1.1
#
# 补偿项二：duckdb 漏声明 pytz
#   duckdb 2.0.0 的 Requires-Dist 里**完全没有 pytz**（连 extra 都没有），
#   但它在把 `TIMESTAMP WITH TIME ZONE` 转成 Python datetime 时要求它。
#   实测：`read_ndjson_auto()` 读一个含 `2026-10-01T00:00:00+00:00` 的 NDJSON
#   就直接抛 `Invalid Input Error: Required module 'pytz' failed to import` ——
#   注意这**不是**只有时间桶查询才踩，**连纯读取都失败**。
#
#   后果不是算错，是**静默换引擎**：`knowledge.answer_question()` 的 auto 模式
#   会回落到逐行 Python 扫盘（答案仍对，但慢一个数量级），只在 note 里写一句
#   `engine=builtin`。这与 docs/operations/deps.md §4「引擎不可用必须明示、
#   不许静默」冲突，所以钉进清单，让它不可能缺席。
pytz==2026.6
