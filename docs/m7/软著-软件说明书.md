## 1. 软件概述

本软件面向野外台站（GNSS 观测站）的日常运维，把「数据接入 → 质控 → 设备状态监测 →
故障研判 → 运维调度（高风险动作过人工审批）→ 数据归档 → 运行看板」串成一条**可回放、
可核对**的智能体链路，并附带试运行台账与评测工具。

开发目的：把「模型归因 + 规则裁决 + 人工审批」三层约束落成可运行、可复现的系统，
让每一条结论都能回到具体的工具调用与数据来源。

适用对象：台站运维人员（看结论与工单）、项目评审/复现者（跑回放与核对数字）。

## 2. 运行环境

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 或 Linux（CI 用 ubuntu-latest） |
| Python | 3.11（仅标准库；出图工具可选依赖 matplotlib） |
| 硬件 | 普通笔记本即可（本地模型通道另需 Ollama 与 ≥8 GB 显存） |
| 网络 | 回放与门禁**不需要网络**；取公开数据、接真实模型时需要 |

## 3. 安装与启动

```powershell
git clone <仓库地址> field-station-agent
cd field-station-agent
$env:PYTHONPATH="src"
python -m unittest discover -s tests -t .     # 全量测试（skip 必须为 0）
python harness/selftest.py                    # 五项门禁
python tools/audit_claims.py                  # 文档数字回源
```

无第三方依赖、无需编译；`python -m fieldstation.cli` 是统一入口（`selftest` / `replay` /
`audit` / `sync` / `figures`）。

## 4. 功能模块

| 模块 | 入口 | 功能 | 输出 |
|---|---|---|---|
| 数据接入 | `src/fieldstation/ingest/` | 读 RINEX 2/3（含 gzip）、CSV；公开数据源登记与取数 | 统一观测对象 |
| 质控 | `agents/tools/qc_tools.py` | 周跳/相位阶跃、连续性、量级判据 | 判据计数与历元索引 |
| 设备状态监测 | `agents/tools/station_tools.py` | 读数健康度（缺测/质量标记/阈值状态） | 健康度与状态 |
| 故障研判 | `agents/knowledge.py` + 结论契约 | 检索规程、按证据给结论 | 结构化结论（JSON） |
| 运维调度 | `agents/tools/work_order_tools.py` + `approval.py` | 建工单；高风险动作过人工审批门 | 工单与授权命令包 |
| 数据归档 | `agents/tools/archive_tools.py` + `store/product.py` | 合成/真实隔离归档 | 归档文件与 sha256 |
| 运行看板 | `tools/make_station_dashboard.py` | 台站健康度/告警/工单三类视图（静态页） | HTML + 机读摘要 |
| 回放与评测 | `harness/*_replay.py` | fixture/`--bless`/`--verify-log`；试运行演练；敏感度扫描 | 确定性日志与基线 |
| 试运行台账 | `tools/trial_ledger.py` | 数据源可用性、六类失败分类、汇总 | JSONL 台账 + 汇总 |
| 工程守卫 | `tools/check_desensitization.py`、`env_snapshot.py`、`audit_claims.py` | 脱敏、环境快照、数字回源 | 报告与快照 |

## 5. 操作流程（端到端）

```powershell
$env:PYTHONPATH="src"
# 1) 跑一条完整链路（公开设备读数 + 合成观测 + 事实合成器）
python harness/public_data_chain.py
# 2) 生成看板（三类视图）
python tools/make_station_dashboard.py --log logs/public_data_chain_202401d01.json `
    --page figures/m5_public_chain_dashboard.html --summary logs/public_chain_dashboard.json
# 3) 复校一条已提交的基线（不需要网络）
python harness/m5_pipeline_replay.py --verify-log logs/m5_pipeline_replay.json
# 4) 试运行演练（31 天）
python harness/dryrun_trial.py
# 5) 取公开数据（需要网络；清单在 data/public/manifest.json）
python tools/fetch_public_data.py
```

预期输出：链路 5 阶段 / 7 条消息 / 8 项机械核对全过；看板显示台站健康度、告警与工单；
复校打印逐阶段证据有效。

## 6. 技术特点

1. **确定性回放**：trace 不含时间戳与随机量，同一输入两次运行逐字节相同；基线用
   sha256 钉死（fixture + 日志 + `--verify-log` 复校）。
2. **证据链**：每条结论必须引用成功的工具调用（`call_id`），跨阶段不能借用证据；
   结论契约机械校验。
3. **人工审批门**：高风险设备动作（重启/断电/配置下发等）在链路上停得住，放行与拒绝
   两条路径都有端到端审计。
4. **共享黑板**：台站/告警/工单上下文受控读写，CAS 版本、声明式作用域、线程安全。
5. **公开数据**：数据源登记（来源/许可/校验和），活响应按规范化摘要校验。
6. **可复现工程**：五项门禁、数字回源、脱敏守卫、环境快照、干净环境重跑记录。

## 9. 边界与限制

- 当前基线用**固定种子合成样本**（真实台站样本受 #28/#33 阻塞），看板与报告均标注；
- 公开 GNSS 观测自 1999 年起均为 CRINEX（gfzrnx 私有紧缩），本软件按既有决定不解码
  （见 issue #99），公开数据目前覆盖**设备侧环境读数**；
- 本地模型通道为 `qwen3:8b`；API 通道选型见 `docs/decisions/2026-10-20-API通道选型与额度.md`
  （Proposed，额度未实测前不进正式指标）；
- 评测口径见 `docs/operations/evaluation-protocol.md`（预注册）。
