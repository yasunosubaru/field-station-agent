## 结论

1. **链路是通的，且可复现**：五阶段链在公开设备读数 + 合成观测上跑通，8 项机械核对
   全过；同一输入两次运行逐字节相同，基线用 sha256 钉死。
2. **「模型归因 + 规则裁决 + 人工审批」三层约束落成了代码**：结论必须引用成功的工具
   调用，高风险设备动作在链路上停得住，放行与拒绝两条路径都有审计。
3. **演练数字支持「能用」但不支持「够好」**：31 天里 15 次注入全检出、16 个干净日零误报，
   但**单历元尖峰 1–20 cycle 全部检不出**——这是质控判据的已知边界，已写进报告与台账，
   不作为能力宣称。
4. **还没到结题标准的地方**：真实台站样本未到位（#28/#33），公开 GNSS 观测受 CRINEX
   阻塞（#99），因此当前所有业务数字都建立在「公开气象 + 合成观测」上，报告中逐处标注。
