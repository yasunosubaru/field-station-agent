## 源程序文档怎么重新生成

```powershell
$env:PYTHONPATH="src"
python tools/make_copyright_source.py
```

它会重写 `软著-源程序.txt` 与 `logs/copyright_source_summary.json`；两次生成逐字节相同
（`tests/test_copyright_source.py` 钉住）。代码增删后**必须**重新生成并提交，否则源程序
文档与仓库不一致。

## 口径一致性

- 软件名称与版本（`野外台站智能体运行与评估系统 V1.0`）在三处一致：源程序页眉、
  说明书、申请信息表；
- 源程序文档只含本仓原创代码；派生件（`PROVENANCE.md`）与移植件（各文件头「移植说明」）
  在说明书 §7 如实说明；
- 说明书里的数字都能回源：源程序规模见 `logs/copyright_source_summary.json`，
  全仓规模见 README 机维护块（`tools/audit_claims.py` 回源）。
