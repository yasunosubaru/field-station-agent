## 表 C：传感器字段清单（成员A，填进 [数据字典](数据字典.md)）

**不要在这张表里重填一遍字段**，这张表只是索引，字段的完整信息填进数据字典。

| 传感器类别 | 字段名（厂商原样） | 中文释义 | 填进数据字典了吗 |
|---|---|---|---|
|  |  |  |  |

字段名沿用厂商叫法，不要自己翻译 —— 翻译过的名字在 M2 接真实数据时会对不上。

必须问清楚的四件事，写进数据字典对应列：

1. **单位** —— V 还是 mV
2. **采样率** —— 有几种，多久一次
3. **缺失标记** —— 设备用什么值表示缺测（这列错了，M3 会把缺测当正常值算）
4. **质控判据** —— 现有的判异常规则，没有就写「待补」

### 验收

- 数据字典的必填列除「待补」外无空缺（`python tools/check_datadict.py` 能过）
- 字段名与厂商文档或设备界面一致
