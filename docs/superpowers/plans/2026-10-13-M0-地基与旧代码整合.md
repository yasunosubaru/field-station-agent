### 对 spec §2 目录树的一处偏离（需知悉）

spec §2 把 `schema.py` 与 `constants.py` 放在 `ingest/` 下。实测依赖图显示这会产生**包级循环**：

```
ingest/schema  →  ingest/../rules/constants      (schema 要 MISSING)
rules/qc       →  rules/constants, ingest/schema
```

即 `ingest` 与 `rules` 互相依赖。本计划改为把它们放在包根：

```
src/fieldstation/constants.py      # 无内部依赖
src/fieldstation/model.py          # ← schema.py，依赖 constants
src/fieldstation/rules/qc.py       # 依赖 constants、model
src/fieldstation/ingest/*.py       # 依赖 model、constants
src/fieldstation/synthetic.py      # 依赖 constants、model
src/fieldstation/store/product.py  # 依赖 model、synthetic
```

依赖图为无环 DAG。除此之外与 spec §2 一致。
