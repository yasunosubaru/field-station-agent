## 11. 已知的坑（新会话必读）

| 坑 | 说明 |
|---|---|
| **`.deps/` 不入库** | 干净检出后必须按 `docs/operations/deps.md` 重装；Python 用 `.deps/venv/Scripts/python.exe`（3.11.15） |
| **`git config --global http.proxy` 是死端口 7897** | Clash 实际在 **7900**。push 必须 `git -c http.proxy=http://127.0.0.1:7900 push origin main` |
| **`Get-FileHash` 靠不住** | 负载下会报「命令不存在」；改用 `[System.Security.Cryptography.SHA256]::Create()` |
| **`.ps1` 必须纯 ASCII** | PowerShell 5.1 把无 BOM 的 `.ps1` 当 ANSI 读，中文会打破引号配对 |
| **`sync_code_counts.py` 要先 `git add -N`** | 否则拒绝执行 |
| **mcp 是 2.x** | `FastMCP` 已改名 `MCPServer`（`from mcp.server.mcpserver import MCPServer`）；**不要 pin `mcp<2`** |
| **`pulp` 必须 <4** | 4.x 是 Rust 重写，经典写法全废 |
| **`ortools` 与 `highspy` 不能同进程** | 静态打包了不同版本 HiGHS，会 `undefined symbol` |
| **DuckDB 2.0.0 不声明 pytz** | `import duckdb` 成功但 `read_ndjson_auto` 遇 ISO 时间会失败；已进 `requirements-v4.txt` |
| **`tests/test_botd_queue.py` 是 18 项不是 69 项** | 「69」是历史误记 |
| **行数有三种算法，差 10%** | `Get-Content .Count` / `Measure-Object -Line` / `ReadAllLines().Length` 结果不同（738 / 657 / 724，同一个文件）。**本表统一用 `ReadAllLines().Length`** |
| **`dist/` 里的 exe 不是当前架构的产物** | 是 .NET WPF 壳；当前 Electron 架构从没打过包 |
| **ADR-009 的「降级梯度」是 AI 补的** | 11-04 18:52（`de49a0a`）由 AI 加入，不是负责人定的 |
