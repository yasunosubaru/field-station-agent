# ADR-006：API 通道选型与额度（X-1 第 3 项）

- 状态：**Proposed**（额度与可复现性待实测；实测后改 Accepted / Rejected）
- 日期：2026-10-20
- 关联：spec §5、§10.3；issue #71、#50；`tools/probe_provider_live.py`

## 背景

spec §5 定的是双轨：**回归基线走本地模型**（离线、可回放），**正式数字走 API**。
但项目总经费 1000 元、没有 API 预算，所以 §10.3 要求在 M2 结束前回答两件事：
API 最终选哪家、免费额度是否覆盖到 2027-08。

当前实现状态：`agents/providers/` 只有 `fake`（测试/回放）与 `ollama`（本地通道，
`qwen3:8b`）；API 通道尚未接入。`get_provider` 的既有纪律是**不留占位分支**：
新通道 = 一个真实分支 + 配置项。

## 决定

1. **回归/回放基线固定用本地 Ollama `qwen3:8b`**（`config/providers.json`：
   `temperature=0`、`seed=42`、`think=false`）。它已接入、断网可跑，是评测底座成立的
   前提；M6 的正式指标也优先用它出数。
2. **正式数字的首选 API 通道 = DeepSeek**。理由：OpenAI 兼容协议，接入只需加一个
   provider 分支（标准库 `urllib` 即可，不引 SDK）；中文与技术文本的归因表现满足
   任务；学生免费额度通道是 spec §5 点名的候选之一。
3. **备选 = 通义 DashScope（Qwen）**。同样 OpenAI 兼容；DeepSeek 额度不可得时切换，
   切换成本只是配置与一个分支。
4. **额度未实测前，API 数字不进入正式指标**。先用本地通道出数，报告里标注模型
   规模与硬件；API 只作为「拿到额度后的补充/对照」。
5. **额度拿不到就不买**。按 spec §5，以本地模型结果作为结题指标，如实标注模型规模；
   不引入第三方代理、不使用共享 key、不把观测数据传到未确认合规的通道。

## 待验证清单（实测后逐项回填）

| 项 | 判据 | 方法 | 结果落点 |
|---|---|---|---|
| 免费额度覆盖到 2027-08 | 官方页面/客服的书面确认 + 实际调用量记录 | 申请后按周记录用量 | 本文档修订记录 + `logs/` |
| `temperature=0` 可复现 | 同一输入 5 次，结论 `fault_type` 一致率 | `tools/probe_provider_live.py --runs 5`（API 分支接入后同样跑） | `logs/probe_provider_*.json` |
| 数据合规 | 观测数据可上传、不含台站敏感信息 | 与指导教师确认；必要时脱敏 | 本文档 |
| 密钥管理 | key 只在环境变量或 `config/*.local.json`（gitignored） | 代码审查 + `tools/check_desensitization.py` | — |
| 限流 / 超时 | 单事件重试与退避策略明确 | 接入时实测 | `harness/REPRODUCE.md` |
| 价格 | 以申请时官方页面为准 | **本记录不写未核实数字** | 本文档 |

## 被否的方案

- **先接一个通用 OpenAI 代理**：引入未知第三方与合规风险，价格与额度都不透明。
- **在 `get_provider` 里留 `NotImplementedError` 占位**：provider 层的既有纪律明确
  不留占位分支 —— 会让回放评测以为还有别的执行路径。
- **把 key 写进 `config/providers.json`**：公开仓库，直接泄露；只允许 env 或
  `config/*.local.json`（已 gitignored）。
- **额度不确定就按 API 出正式数字**：通道不稳定，事后无法解释口径，也违背
  「每个数字可回源」的验收。
- **为了额度去用共享/转卖 key**：来源不可控，数据合规无法保证。

## 后果

- M6-3 的成本记录按「本地 / API 各一组」；只有本地时明确标注模型规模与硬件。
- API provider 分支在额度实测通过后实现；`chat(messages, tools) -> response`
  协议不变，M6 的评估协议（`docs/operations/evaluation-protocol.md`）不改。
- 若额度不可得，本文档状态改 **Rejected** 并写明替代口径（本地结果 + 模型规模），
  M6 报告按此口径写，不留「等以后有额度再说」的悬空结论。
