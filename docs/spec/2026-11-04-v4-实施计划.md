### 现场发现的方案修正（已写回文档）

1. **`app.install` 不再是必经**：可选应用是"解压到 `%APPDATA%\...\noncoreapps\` + 登记一行"，
   已做 `tools/provision_noncore_apps.py`（幂等、12 项单测）；GUI 路径保留为通用能力。
2. **`graph.newproject` 从"可能只能人工"翻成"可自动"**：用系统安装的 Graph 加调试端口。
3. **新增坐标模式**：语义选择器和 AX 树都抓不到的元素（div 卡片、图标块），
   用"钉视口 + 记录中心点 + 命中校验"处理。
4. **UIA 的能力边界**：看不到 Chromium 内容，但能驱动原生对话框；文本输入要剪贴板/键盘。

## 0. 依赖关系（谁挡谁）

```
W0 契约 ──┬─> W1 RPA 收口 ─────────────┐
          ├─> W2 Electron 壳 + 四视角 ──┼─> W3 套件台重做
```
