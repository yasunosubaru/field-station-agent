# UI 壳（Convert / Manage / Playback）

> 状态：**v0.1 可运行**。本文记录 `逆向/04_重实现/packages/app/` 的第一版本地 Web 壳——
> 它把已有的协议层与转换管线接到一个可打开就用的界面上，不追求像素级还原原版。
> 证据等级沿用 `_约定.md`：`[观察]` 指本仓库代码/实测结果，不涉及对原版的新取证。

---

## 1. 定位

`packages/app` 是一个**零依赖的 Node HTTP 服务 + 单页前端**。它只做三件事：

1. 把 `packages/protocol` 的确定性能力（SBF 拆帧、EDIE 解码、ASCII/缩略 ASCII/BINARY/KML/RINEX 写出）暴露成 HTTP 端点；
2. 提供一个不依赖外网的单页界面：Convert / Manage / Playback 三页；
3. 把「Playback 引擎」与「Graph 应用」的接入位先留出来，**不依赖**平行任务。

它**不**重新实现任何协议逻辑：拆帧、解码、编码全部 `import` 自 `packages/protocol/src/*.ts`
（只读引用，未修改一行）。

## 4. 端点清单

所有响应都是 JSON（下载端点除外），错误体固定为 `{"ok":false,"error":"…"}`。
除 `POST /api/convert` 外均为只读 `GET`；`HEAD` 可用。

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/` | — | 单页 HTML（内联 CSS/JS）；CSP 只允许 `'self'` + 内联 |
| GET | `/api/health` | — | 服务名、版本、Node 版本、samples 相对路径、格式清单、预览/请求体上限 |
| GET | `/api/captures` | — | 枚举 samples 下 `.gps` / `.bin`（递归，深度 ≤ 6），返回 `path/name/bytes` |
| POST | `/api/convert` | body `{"capture":"…","format":"ASCII","at":"ISO 可选"}` | 跑转换；返回元信息 + 前 200 行预览 + `downloadUrl` |
| GET | `/api/download` | `token` | 下载上一次转换的完整产物（内存缓存，重启即失效） |
| GET | `/api/logs` | `capture` | 按 messageId 聚合：条数、CRC 失败数、GPS/UTC 时间范围、示例一行 |
| GET | `/api/records` | `capture`,`msgId`,`offset`(默认 0),`limit`(1..25) | 解码指定报文的第 N 帧，返回头部信息 + 字段表 |

### 4.1 `POST /api/convert` 细节

- `format` ∈ `ASCII` / `ABBREV_ASCII` / `BINARY` / `KML` / `RINEX21`，缺省 `ASCII`，大小写不敏感。
- 只输出 CRC 通过的记录；ASCII/缩略 ASCII 统一 CRLF 行尾；BINARY 是原记录逐字节拼接。
- 预览是**按行**截断：最多 200 行。`truncated` 表示总行数是否超过 200。
  - 例如 `clean-9600.gps → ASCII` 只有 119 行（每行很长），因此 `truncated=false`，
    全文放在 `text` 里（478 KB）；
  - 同一抓包的 `ABBREV_ASCII` 有 6 294 行，`truncated=true`，`text=null`，只给 `preview`（前 200 行）。
- BINARY 没有文本，`text=null`，`preview` 是 200 行十六进制 dump。
- 响应字段：`fileName / bytes / lineTotal / shownLines / truncated / binary / text / preview /
  downloadUrl / elapsedMs / records{total,accepted,dropped,textRecords} / at`。
- `text` 与 `preview` **互斥**：正文不超过 200 行时给 `text`（完整），超过时给 `preview`（截断）；
  两者不会同时出现，避免把 489 KB 发两遍。
- 计数口径：`total` 是 mirror 模式拆出的记录数（CRC 字段为 0 的记录在拆帧层即被丢弃，不计入）；
  `dropped` 是 CRC 字段非 0 但校验不符的记录；`textRecords` 是 `#`/`%`/`<`/`$`/`[` 文本记录，
  不参与任何二进制转换。对 `clean-9600.gps`：119 / 119 / 0 / 0；对 `broad-clean.gps`：1722 / 1721 / 1 / 0。

### 4.2 下载

`token` 是 9 字节随机十六进制，进程内最多保留 40 份产物（约 300 MB 上限的粗略保护，实际按条目数）。
`Content-Disposition` 同时给 ASCII 回退名与 `filename*=UTF-8''…`。
旧 token 被淘汰后返回 404，提示重新转换。

### 4.3 路径安全

`[观察] packages/app/src/paths.ts`：

- 拒绝绝对路径、盘符（`C:`）、空段、`.`、任何 `..` 段、NUL、非 `.gps/.bin` 扩展名；
- 解析结果必须仍在 `SAMPLES_DIR` 内（`relative()` 不以 `..` 开头且非绝对）；
- 也接受裸文件名（如 `clean-9600.gps`），查找顺序：精确相对路径 → `samples/convert/<name>` → 全树唯一 basename；
- 重名且无法唯一确定时返回 409 并列出候选；
- **不做任何写入**：转换结果只存在内存，样例目录始终只读。

### 4.4 缓存

- `capture.ts` 以 `(绝对路径, 大小, mtime)` 为键缓存拆帧结果，最多 4 份。3 MB 抓包二次访问不再重拆。
- `edie-layouts.json`（496 KB）每进程只解析一次。
- 产物缓存与帧缓存均在重启后失效，无持久化。

## 5. 前端三页

单文件 `src/web/index.html`，无构建步骤、无外部请求；`fetch` 只打同源 `/api/*`。

### Convert
- 抓包下拉（来自 `/api/captures`）、格式下拉（含一行格式说明）、开始/清空。
- 结果卡片：产物名、大小、行数、有效记录、耗时、下载按钮。
- 预览：等宽字体 + 行号栏，纵向滚动 430 px，横向滚动承载超长 ASCII 行；
  标题旁徽标显示格式（`ASCII` / `HEX`），右侧说明「全部 N 行」或「仅显示前 200 / N 行，完整内容请下载」。
- 下载按钮直接指向 `/api/download?token=…`，由浏览器保存。

### Manage
- 统计卡：总记录 / CRC 有效 / 丢弃 / 报文类型数；下方一行显示抓包与首条 UTC。
- 表格：ID、名称（无 EDIE 布局时标「无布局」）、条数、CRC 失败、GPS 与 UTC 时间范围、示例一行。
- 点击任意行 → 下方「字段表」：
  - 头部 chip：帧序号、端口、序号、GPS、UTC、时间状态、接收机状态、载荷/整帧字节、CRC；
  - 上一帧 / 下一帧（`offset` 翻页），字段筛选框（按路径或显示值）；
  - 三列：字段路径、显示值（枚举名/格式化文本）、原始值（与显示值相同时留空）；
  - 单帧最多 800 个字段，超出标注；RANGE 一帧约 601 个字段（1 个计数 + 60 颗星 × 10）。
- 类型筛选框同时匹配 ID、名称与示例内容。

### Playback（占位）
- 明确的 `NOT IMPLEMENTED` 标记与说明：引擎由平行任务实现，本壳不依赖它。
- 静态 SVG 时间轴：轨道、刻度、播放头；播放/暂停/回起点按钮全部 `disabled`。
- 预留两个接入点说明：帧流（`SbfFrame[]` + GPS 周/毫秒）与视图复用（`decodeEdie`）。

## 7. 当前限制

1. **Playback 是占位**，没有任何回放逻辑；Graph 也尚未出现（只在文档里留了投影端点建议）。
2. **只读**：页面上传/落盘均不支持；服务端不写 samples，也不写临时目录。抓包必须事先放进
   `逆向/00_来源/samples/`（`.gps` / `.bin`）。
3. **预览按行不按字节**：一行可能 4 KB，119 行的 ASCII 仍有约 478 KB 进入 JSON。
   若将来出现单行数 MB 的报文，需要给 `textPreview()` 增加字符上限（当前未加，避免悄悄改变「全文」语义）。
4. **下载链接是内存 token**：进程重启、或超过 40 次转换后旧链接失效。
5. **无并发控制**：两个请求同时转换同一抓包会各自跑一遍管线（帧缓存只省拆包，不省编码）。
   大抓包（`broad-clean.gps`，3.2 MB）ASCII 转换约 1.8 s，足以让用户连点；前端已禁用按钮，但 API 无锁。
6. **格式面**：仅接已实现的 5 种。RINEX 3.x、Hatanaka、按日志/时间窗筛选、拆分等原版 Convert 能力未接。
7. **时间语义沿用镜像缺陷**：UTC 列与 Summary 一样按「GPS 秒当 UTC」显示，不做 18 s 闰秒修正
   （与 `summary.ts` 的已知缺陷一致；Playback 真正做时钟时应改用 `gpsToUtcDate()`）。
8. **单机单进程**：只监听 `127.0.0.1`，无鉴权、无 TLS、无多用户；CSP 允许内联脚本（因为页面就是内联的）。
9. **无国际化**：界面固定简体中文；原版的 20/9 语言切换未接。
10. **目录假设**：`SAMPLES_DIR` 在模块加载时按 `import.meta.url` 推出（`packages/app/src` 上溯到仓库根）。
    运行时移动仓库目录需要重启。
