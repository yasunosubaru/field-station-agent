## 16.5 手上刚查出、**还没修**的四个协议缺陷

> **2026-11-01 状态：已全部修完**，189 行 → 0，整文件 SHA-256 与 oracle 相同。
> 修法与实测见 `09_EDIE消息字典与ASCII一致性.md` §9.x.5（含 `%m` 的标志位规则与
> `%R` 内嵌 CRC 取反这一条 8/8 拟合）。下表保留原始记录。

素材：`逆向/00_来源/samples/live-20261031/remote-23types.sbf`（2 018 852 B，远程抓的 23 类报文）
+ 同目录 `golden-remote-23types.ASCII`（套件 CLI 产出，3 845 232 B）。

比对结果：1208 行里 **189 行不同**，集中在 5 类、**4 个根因**：

| 类型 | 行数 | 现象 | 根因 |
|---|---:|---|---|
| `ITPSDFINALA` / `ITPSDDETECTA` | 149 | 原版把 **1024 个采样值全展开**（6267 字符），我们只打 `1024*78e05208`（123 字符） | 数组/重复字段没展开 |
| `LOGLISTA` | 21 | 原版打日志名 `RXSTATUSEVENTA`，我们打数字 `2097246` | 名字表没查 |
| `ITDETECTSTATUSA` | 15 | `0000000f` vs 我们 `0000000F` | 位域十六进制大小写 |
| `RXCONFIGA` | 4 | 原版把内嵌配置文本原样印出，我们打 `170*a8618e27` | 变长文本块没解码 |

**修 ITPSD 数组展开 = GRIT 频谱曲线能画真数据**（B2 随之解决）。

比对脚本（可复用，在 `%TEMP%\opencode\`）：`cmp-ascii.cjs`（按类型计数）、`cmp-lines.cjs`（多重集）、
`pairdiff.cjs`（同类型首行逐字段比）。

## 16.6 关键工具与方法（不掌握会走弯路）

### 无界面 oracle —— 套件自带 CLI

```powershell
& "C:\Program Files\NovAtel Inc\NovAtel Application Suite\NovAtelApplicationSuite.exe" `
    -a -o <纯 ASCII 输出目录> <纯 ASCII 输入文件>
```

- 输出落在 `<out>\<name>\Converted_On_<YYYYMMDD>_T<HHMM>\ASCII\<name>.ASCII` + `Summary_<name>.txt`
- **坑：参数里的路径必须纯 ASCII 无空格**，中文路径会静默报 `Please provide a file to convert`
- 我们自己的等价命令：`node packages/cli/src/convert.ts <input> --to ASCII --out <dir>`

### 远程采数与截图

见 `逆向/tools/remote/README.md`。要点：

- `ssh nova-desktop`（提权会话）；套件在跑时会占住某个 COM 口（实测 COM9），抓包用空闲口
- **截图不需要 RDP**：`PrintWindow(hwnd, hdc, 2)` 直接拿窗口像素；但必须在**交互会话**里跑，
  所以用 `run-in-session.ps1` 建 `LogonType Interactive` 计划任务
- 所有 `.ps1` **必须纯 ASCII**（PS 5.1 无 BOM 按 GBK 读，中文字面量会解析失败）

### 比对工具

- 像素：`node 逆向/tools/ui-diff.ts --a <参照> --b <实现> [--regions '{...}']`
- 参照图一律 2560×1600 整屏；**先验 DPI**（用已知 CSS 尺寸反推，例如 `.tile` 宽 392）
- 截图一律整屏，不许 `region` 裁剪

## 16.8 不能忘的规矩

1. **模型**：只用当前会话的模型；派子任务时**不许**传 `model` / `variant`（继承即正确）。
2. **不许探测式请求**：不准用填充串试上下文上限/限流，不准短时间连发多个模型。
3. **自主推进**：报错/失败自己查日志、读代码、换方案，别停下来问；只有"删数据、要钱、需求歧义、
   已穷尽方案"才问。
4. **汇报**：先说结论再给证据；不伪造成功；缺数据就写 `--` 并说明原因。
5. **提交**：中文 commit message，`git -c core.quotepath=false`；只 add 自己改的文件（仓库里有
   `NovAtel/`、`qc_agent_smoke` 等不该提交的东西）。
6. **`.ps1` 纯 ASCII**；采样路径纯 ASCII；截图整屏。
