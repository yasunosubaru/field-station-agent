### 一条重要发现：`UNKNOWN` 行有 oracle

套件 CLI 支持 `--unknown-bytes=[file|interleave|ignore]`：`file` 会把**无法识别的字节**单独写成
`<name>.UNKNOWN`，`ignore` 只计数不落盘。实测 b2：summary `UNKNOWN 6875`，`.UNKNOWN` 文件 7056 B
（内容就是 `<OK` / `<ERROR:…` / `[USB2]` 这类应答与端口标记）；b1 5386 B / 记 3695；b3 364 B / 记 224。
**这三组差值不是常数**，说明 summary 的计数与落盘字节不是同一口径——但有了这个文件就能做逐字节反推
（把我们的"无法成帧字节"和套件的 `.UNKNOWN` 直接 diff，找出差的那几十字节到底是什么）。
台账 A2 的下一步就用它。

另：默认（不带任何开关）转换也会把 `RANGECMP*` 展开成 `RANGE`（b2 638→699），`--expand-cmp` 不是
"要不要展开"的总开关；这条已在 b1–b5 的 golden 里体现。

## H. 2026-11-02 实机复核：星座锁与 OEM729 的能力边界

问的是“B 类里只能换机器/换授权的项，凭 OEM729 能不能搞定”。实测结论：**代码/格式能，实机证据不能。**

### H.1 星座锁（这台机实测）

`MODELFEATURES` 里 `GALILEO / NAVIC / SBAS` 本来被 `LOCKOUTSYSTEM` 锁着。发：

```
UNLOCKOUTSYSTEM GALILEO   -> <OK
UNLOCKOUTSYSTEM SBAS      -> <OK
UNLOCKOUTSYSTEM NAVIC     -> <OK
```

`RXCONFIG` 出现 `#UNLOCKOUTSYSTEMA;…`。等 45 s 后 `SATVIS2A`：

| 系统 | 可见/跟踪 | 颗数 |
|---|---|---|
| GPS | TRUE / TRUE | 32 |
| BEIDOU | TRUE / TRUE | 53 |
| QZSS | TRUE / TRUE | 5 |
| SBAS | TRUE / FALSE | 0 |
| GALILEO | 没有这一行 | — |
| GLONASS | 没有这一行 | — |
| NAVIC | 没有这一行 | — |

**解锁命令被接受、配置也真的改了，但这台机仍不跟踪 Galileo / GLONASS / NavIC**——所以不是
`LOCKOUTSYSTEM` 这一层能解决的，是固件/型号层面。SBAS 是 0 颗可见（不是被锁），换到能看见
BDSBAS/WAAS 的位置才可能有。

探针结束按原值恢复：`LOCKOUTSYSTEM GALILEO / SBAS / NAVIC` 各 `<OK`，`RXCONFIG` 里三条
`#LOCKOUTSYSTEMA` 又回来了。没有留下改动。

### H.2 `MODELFEATURES`（b1，2442/570227.195）

```
SINGLE ANTENNA
RTK_TX AUTHORIZED
ALIGN_HEADING AUTHORIZED, ALIGN_RELATIVE_POS AUTHORIZED
NTRIP UNAUTHORIZED
IMU UNAUTHORIZED, INS UNAUTHORIZED
RTK_FLOAT UNAUTHORIZED, RTK_FIXED UNAUTHORIZED
PPP UNAUTHORIZED, API UNAUTHORIZED
INTERFERENCE_MITIGATION UNAUTHORIZED
```

OEM729 只有一个 MMCX 射频口（官方 `OEM729_Electric_Environment_Specs.htm`：Antenna connector
MMCX female），所以 `ALIGN_HEADING AUTHORIZED` 也做不了双天线；RTK 是“能发差分”但不是“能解 RTK”。

### H.3 结论（用于口径）

- **能凭 OEM729 做完**：B 类的代码项；GPS/BDS/QZSS/ITK 的真机数据；SBAS 0 颗这一事实。
- **必须换机器/授权**：Galileo/NavIC/GLONASS 跟踪、RTK fix、双天线/ALIGN、SPAN/IMU、Wi-Fi AP、
  内部存储、LUA（API）、PIM222A/G-III/Longhorn。
- 对这些项，代码可照手册与原版前端写完、可用合成帧/合成抓包驱动 UI，但报告里必须标“未实机验证”。
